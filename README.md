# PACE-MAKER

과제 분량과 마감일, 요일별 학습 가능 시간을 바탕으로 오늘 해야 할 분량을 계산해 주는 Streamlit 앱입니다.
구글 캘린더를 연동하면 그날 잡힌 일정 시간만큼 공부 가능 시간을 줄여서 하루 목표를 다시 나눠 줍니다.

## 실행

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

`python app.py` 로 실행하면 `missing ScriptRunContext` 경고만 나오고 화면이 뜨지 않습니다. 반드시 `streamlit run` 으로 실행하세요.

## 구글 캘린더 연동 설정

구글 API 설정이 없어도 앱은 그대로 동작하고, 연동 기능만 꺼집니다.

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 프로젝트를 만듭니다.
2. **API 및 서비스 → 라이브러리**에서 **Google Calendar API**를 사용 설정합니다.
3. **OAuth 동의 화면**을 설정합니다.
   - 사용자 유형: 외부
   - 범위(데이터 액세스): `https://www.googleapis.com/auth/calendar.events` (일정 보기·수정)
   - 게시 상태가 '테스트'인 동안에는 **테스트 사용자**에 등록한 구글 계정만 연동할 수 있고, 연동이 7일 뒤 만료됩니다.
4. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - 승인된 리디렉션 URI: `http://localhost:8501` (배포한다면 `https://<앱 이름>.streamlit.app` 도 추가)
5. `.streamlit/secrets.toml.example` 을 `.streamlit/secrets.toml` 로 복사하고 클라이언트 ID, 클라이언트 보안 비밀, 리디렉션 URI를 채웁니다.
   Streamlit Cloud에 배포했다면 앱 설정의 **Secrets**에 같은 내용을 붙여 넣습니다.
6. 앱을 다시 실행한 뒤 **일정 관리 → Google 계정으로 연동하기**를 누릅니다.

## Streamlit Cloud에 배포할 때

- `secrets.toml` 은 깃허브에 올라가지 않으므로, 앱 관리 화면의 **Settings → Secrets** 에 같은 내용을 직접 붙여 넣어야 합니다.
- 이때 `redirect_uri` 는 배포 주소(`https://<앱 이름>.streamlit.app`)로 바꾸고, 구글 클라우드 콘솔의 **승인된 리디렉션 URI** 에도 같은 주소를 추가합니다.
- Streamlit Cloud의 파일 저장소는 앱이 재시작되면 초기화됩니다. `users.json`, `tasks.json` 도 깃허브에 없으므로, 배포된 앱에서는 회원가입부터 새로 해야 하고 재시작 시 데이터가 사라질 수 있습니다.

## 일정 반영 방식

- 하루 공부 가능 시간 = 요일별 학습 가능 시간 − 그날 구글 캘린더 일정이 차지하는 시간 (최소 0시간)
- 겹치는 일정은 한 번만, 자정을 넘기는 일정은 날짜별로 나누어 계산합니다.
- '한가함'으로 표시한 일정과 내가 거절한 일정은 빼지 않습니다.
- 종일 일정은 기본적으로 무시하고, **일정 관리**에서 '종일 일정이 있는 날은 공부하지 않기'를 켜면 그날을 0시간으로 처리합니다.
- 남은 분량은 마감일까지 날짜별 공부 가능 시간에 비례해 나누고, 그중 오늘 몫을 추천 목표로 보여 줍니다.

## 오늘의 계획 (과제 간 시간 배분)

- 과제마다 "1페이지/1문제당 예상 시간(분)"을 정할 수 있습니다. 비워 두면 페이지 5분, 문제 3분으로 계산합니다. 과제 카드의 **진행 그래프 · 설정**에서 언제든 바꿀 수 있습니다.
- 과제마다 오늘 몫 = 남은 시간 × (오늘 공부 가능 시간 ÷ 마감까지 공부 가능 시간 합)
- 몫을 다 합쳐도 오늘 가능 시간 안이면 그대로 배정하고, 넘치면 **마감이 빠른 과제부터** 채웁니다. 남는 시간은 여유 시간으로 표시합니다.
- 마감일 순으로 필요한 시간과 가능한 시간을 누적 비교해서, 모자라면 "마감까지 약 N시간 부족" 경고를 띄웁니다.

## 페이스 체크 · 기록 그래프

- 기록할 때마다 날짜별 기록이 쌓입니다(같은 날 여러 번 기록하면 합산).
- 계획 곡선: 등록일부터 마감일까지 요일별 학습 가능 시간 비율로 "어제까지 해 두었어야 할 분량"을 계산합니다.
- 지금 진행량이 계획 곡선의 며칠째에 해당하는지 보고 **N일 앞섬 / 계획대로 / N일 뒤처짐**을 표시합니다.
- 과제 카드의 **진행 그래프 · 설정**에서 실제 누적(실선)과 계획(점선)을 비교할 수 있고, 홈에서는 연속 학습일과 뒤처진 과제를 보여 줍니다.
- 이 기능 이전에 등록한 과제는 그때까지 한 분량을 출발점으로 삼아 오늘부터 계획을 다시 그립니다.

## 과제 → 구글 캘린더

- 앱에서 등록한 과제는 마감일에 종일 일정 `[마감] 과제명 · 진행률%` 로 구글 캘린더에 올라갑니다. 다 끝낸 과제는 `[완료]` 로 바뀝니다.
- 진행률을 기록하면 일정 제목과 설명이 갱신되고, 앱에서 과제를 삭제하면 구글 캘린더의 일정도 삭제됩니다.
- 연동 전에 등록한 과제는 **일정 관리 → 과제 마감일 구글 캘린더에 올리기** 로 한 번에 올릴 수 있습니다.
- 이 일정은 '한가함'으로 표시되고, 앱이 만든 일정이라는 표시가 붙어 있어 공부 가능 시간 계산과 앱 화면의 구글 일정 목록에서는 빠집니다.
- 구글 캘린더에서 그 일정을 지웠다면 다음에 진행률을 기록하거나 동기화할 때 다시 만들어집니다.
- 예전에 읽기 전용 권한으로 연동했다면 **일정 관리 → 권한 업데이트하고 다시 연동하기** 를 한 번 눌러야 합니다.
